# Obsidian starter files

Copy `Collections.base` and `Templates/` into the root of a separate Obsidian vault. Create the category folders `GitHub-Projects/`, `Websites/`, and `DIY-Projects/` there. The sample Base uses Obsidian's built-in Bases feature and filters Markdown notes by folder and YAML properties.

These files contain templates only. Do not place private notes, database files, credentials, or local application state in this source repository.
